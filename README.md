# tienda_china
GroStop — E-Commerce de Abarrotes

Stack Tecnológico
* **Frontend:** HTML5, CSS3, Bootstrap, Jinja Templates.
* **Backend:** Python, Flask.
* **Base de Datos:** MySQL.



 Pasos de Instalación y Configuración

1. Clonar el repositorio
```bash
git clone <URL-DEL-REPOSITORIO-DE-TU-EQUIPO>
cd ECommerce-Grocery-Store

2. Crear y activar el entorno virtual
 * En Windows (CMD / PowerShell):
   python -m venv venv
venv\Scripts\activate

 * En Mac / Linux:
   python3 -m venv venv
source venv/bin/activate

3. Instalar las dependencias
pip install -r requirements.txt

4. Configurar la Base de Datos
 * Abre tu gestor de MySQL.
 * Restaura la base de datos usando el archivo Dump.sql incluido en el repositorio.
 * Actualiza tus credenciales de conexión en los archivos de configuración del proyecto.
5. Ejecutar la aplicación
python run.py

Abre en tu navegador: http://127.0.0.1:5000/
